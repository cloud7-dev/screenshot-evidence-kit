# Public Standard Boundary

The public core is a technical evidence packet format. It is not a legal evidence standard.

## Public Core

- Manifest schema
- Hash algorithm and canonicalization
- Redaction metadata
- Sample packets
- Local verifier
- Integrity model docs

## Private or Commercial Layer

- Lawyer directory and connection workflows
- Paid legal pack operations
- Lawyer and customer network data
- Payment, advertising, ranking, and profile systems
- Advanced OCR or AI privacy review
- Hosted SaaS dashboards
- Professional review audit logs

## Product Language

Allowed:

- "technical packet format"
- "local integrity check"
- "optional timestamp proof"
- "not legal advice"
- "does not guarantee admissibility"

Avoid:

- "legal evidence standard"
- "court-approved evidence"
- "admissibility guaranteed"
- "blockchain court evidence"
- "AI legal judgment"
